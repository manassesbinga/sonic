              SONIC DASHBOARD — USAGE GUIDE
═══════════════════════════════════════════════════════════

Commands:

  sonic status           Show metrics once and exit
  sonic dashboard        Live dashboard, refreshes every 2s

Flags (both commands):

  -a, --addr string      Metrics server address (default: localhost:9090)

Examples:

  1. Start Sonic with telemetry enabled:

       sonic dev -c sonic.yaml

     Or using the compiled binary:

       .\dist\sonic-windows-amd64.exe dev -c sonic.yaml

  2. View metrics once:

       sonic status
       .\dist\sonic-windows-amd64.exe status

  3. Live dashboard (press Ctrl+C to exit):

       sonic dashboard
       .\dist\sonic-windows-amd64.exe dashboard

  4. Custom metrics address:

       sonic dashboard --addr 192.168.1.100:9090
       sonic status -a localhost:9091

Integration tests (6 tests):

  go test ./tests/... -run TestCLI_Dashboard -v

  These start a fake metrics HTTP server and validate:
  - Metric parsing from Prometheus text format
  - Dashboard rendering output
  - Server-down error handling
  - Empty metrics handling
  - Many domains (top 5 display)
