por que o sonic é mais rápido
Goja VM — Pure Go
Engine 100% Go, sem CGO, sem boundary cross-language. Compilação para bytecode numa única vez — execução no pool sem overhead de inicialização.
VM Pool × 64
64 VMs pré-aquecidas em sync.Pool. Zero cold start — cada pedido vai direto para uma VM disponível. CPU watchdog com vm.Interrupt() em 50ms.
eBPF Sockmap
Kernel bypass com zero-copy TCP splicing. BPF_MAP_TYPE_SOCKMAP + BPF_PROG_TYPE_SK_MSG — dados transferidos em kernel space sem round-trip para userspace.
Single Leaf Key + CertCache
Uma única chave RSA reutilizada para todos os certificados dinâmicos. Cache com RWMutex — certificates gerados uma vez por domínio e reutilizados.
